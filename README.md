# Eden Perps

Perpetual markets for memes that grew up on [Eden](https://edenfamily.xyz).

Eden is the launchpad on Elysium that takes memes from launch to perpetuals. A token starts on Eden's bonding curve, graduates into a locked Uniswap v4 pool, and the tokens that build real markets become candidates for perpetual futures. Eden Perps is that last step.

## Status

In development. No Eden Perps contracts are deployed, and nothing in this repository is live. The Perps section on edenfamily.xyz is marked "Soon".

Market design, listing criteria, leverage limits and risk parameters will be published here before anything goes live, so traders can read the rules first.
